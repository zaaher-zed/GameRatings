# GameRatings 🎮

GameRatings is a responsive front-end gaming catalog website built with HTML, CSS, and JavaScript.  
The project allows users to explore popular games by category, including Online, MMORPG, Strategy, and Single Player games.

The goal of this project was to practice building a real gaming-style user interface with clean layouts, interactive cards, hover effects, ranking tables, video previews, and a dark theme inspired by modern gaming platforms.

## ✨ Features

- Responsive multi-page gaming website
- Game categories: Online, MMORPG, Strategy, and Single Player
- Interactive game cards with hover animations
- Ranking tables for popular games
- Video preview card on hover
- Scroll-to-top button
- Dark gaming UI inspired by Steam-style interfaces
- Game tags, platforms, prices, and descriptions

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Layout
- CSS Animations
- DOM Manipulation
